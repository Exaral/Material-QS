# Android 16 Quick Settings

A lightweight accessibility-overlay Quick Settings prototype inspired by Android 16 Material Expressive styling.

## Use
1. Install the APK.
2. Open the app and tap **OPEN ACCESSIBILITY SETTINGS**.
3. Enable **Android 16 Quick Settings**.
4. Tap the top 64dp edge to open the panel.

Internet/Bluetooth/Settings open the corresponding system settings; Torch uses CameraManager when a flash is available.
